AI Agent 平台

Agent 平台定义​

AI Agent 平台是一类能够将 LLM 推理能力、工具调用、工作流编排和外部服务集成统一提供给用户和开发者的基础设施。与单一 AI 工具不同，Agent 平台的价值在于：

  • 工作流编排：将多个 AI 调用和工具操作串联成复杂的自动化流程
  • 工具集成：内置或允许接入外部 API、数据库、文件系统等
  • 状态管理：在多步骤任务中维护和传递上下文信息
  • 调试与监控：提供执行日志、错误追踪、成本统计

平台 vs 工具的差异​

维度单一 AI 工具Agent 平台
使用方式单次 Prompt → 输出定义工作流，自动执行多步骤
工具调用不支持或有限支持内置丰富工具库 + 自定义工具
用户类型终端用户开发者 + 非技术用户（低代码）
输出文本/图像触发操作、修改数据、发送通知
可维护性无版本控制工作流版本管理、回滚

工作流市场​

Agent 平台的网络效应来自工作流市场——用户创建并分享自己构建的 Agent 模板：

市场价值​

  • 降低使用门槛：非技术用户可以一键安装他人构建的工作流
  • 长尾覆盖：平台无法覆盖的垂直场景由社区创作者填补
  • 创作者经济：优质工作流的创作者可以获得分成或订阅收入

工作流分类​

常见的工作流市场分类：

  • 内容创作（博客生成、社交媒体自动发布）
  • 数据处理（Excel 分析、CSV 转换、API 数据抓取）
  • 客户服务（FAQ 问答、邮件自动回复）
  • 开发辅助（代码审查、文档生成、Bug 分类）
  • 个人效率（日程整理、会议纪要、邮件摘要）

集成生态​

Zapier 的 AI 化​

Zapier 是最成熟的自动化工具平台，正在深度整合 AI 能力：

  • AI Step：在 Zap 工作流中插入 AI 步骤（文本分类、内容生成、数据提取）
  • Zapier Chatbots：无代码构建 AI 客服 Bot，集成 Zapier 数千个 App 连接器
  • AI Fields：在数据映射中用 AI 动态生成字段值

Make（原 Integromat）​

  • AI Modules：内置 OpenAI、Anthropic、Google AI 模块
  • HTTP + AI 组合：灵活调用任意 AI API 并与工作流集成
  • 视觉化流程编辑器：拖拽式设计复杂的 AI 工作流

n8n AI 化​

  • 开源，可自托管，数据完全私有
  • AI Agent 节点：内置 LangChain 集成，支持 ReAct Agent
  • 工具节点：数据库查询、HTTP 请求、文件操作均可作为 Agent 工具

工作流构建器（低代码）​

Agent 平台的核心用户体验是低代码工作流构建器：

节点类型​

  • 触发节点（Trigger）：定时触发、Webhook、文件变更、新邮件
  • AI 节点（LLM Call）：调用指定模型，配置 System Prompt 和输入变量
  • 工具节点（Tool）：搜索、代码执行、数据库查询、API 调用
  • 逻辑节点（Logic）：条件分支（If/Else）、循环（Loop）、等待（Wait）
  • 输出节点（Output）：发送邮件、写入数据库、推送通知、返回 HTTP 响应

变量传递​

工作流节点间通过变量传递数据：

{{trigger.email_subject}}   # 触发节点的数据
{{step1.ai_output}}         # 前序 AI 步骤的输出
{{step2.json_parsed.name}}  # 解析后的结构化数据

API / Webhook 接入​

Agent 平台必须提供标准化的 API 接入，允许开发者程序化地触发工作流：

常见 API 设计​

POST /api/v1/workflows/{workflow_id}/run
Authorization: Bearer {api_key}
Content-Type: application/json

{
  "inputs": {
    "customer_email": "user@example.com",
    "complaint_text": "我的订单三天未发货..."
  }
}

响应模式：

  • 同步返回（适合短任务，< 30 秒）
  • 异步 + Webhook 回调（适合长任务，返回 run_id，完成后回调）
  • 流式 SSE（适合实时输出场景）

平台商业化路径​

订阅制​

  • 按功能分层：免费（有限工作流数量）→ Pro → Team → Enterprise
  • 适合轻度用户和中小团队

用量计费​

  • 按工作流执行次数、AI Token 消耗或任务步骤数计费
  • 适合用量差异大的用户群

企业版​

  • 私有部署（本地或 VPC 内部署）
  • 自定义模型接入（私有 LLM 或微调模型）
  • 企业级 SSO、权限管理、审计日志
  • SLA 保障

代表产品​

Coze（字节跳动）​

  • 面向开发者和普通用户的 Agent 构建平台
  • 内置插件生态（搜索、图像生成、代码执行）
  • 支持一键发布到飞书、豆包等渠道
  • 国内部署，合规优势

Dify​

  • 开源（Apache 2.0），可自托管
  • 功能完整：RAG 知识库 + 工作流 + Agent + 监控
  • 活跃社区，快速迭代
  • 企业版提供私有部署支持

Flowise​

  • 基于 LangChainJS 的开源低代码平台
  • 极简设计，入门门槛低
  • 适合快速原型验证

LangFlow​

  • 基于 LangChain Python 的可视化编辑器
  • 与 LangChain 生态深度集成
  • 适合已有 LangChain 经验的开发者

竞争格局​

Agent 平台市场呈现出明显的分层竞争格局：

竞争维度​

  • 开源 vs 闭源：开源平台（Dify/n8n）获得开发者信任，闭源平台商业化路径更清晰
  • 垂直化 vs 通用：通用平台面向所有场景，垂直平台（如法律 Agent 平台、销售 Agent 平台）专注特定行业
  • 本地部署 vs 云端 SaaS：数据敏感的企业倾向本地部署，中小团队偏好 SaaS

护城河分析​

  • 工具集成数量：集成越多外部服务，平台价值越高（飞轮效应）
  • 工作流模板库：优质模板积累带来网络效应
  • 开发者生态：插件/工具的第三方开发者数量
  • 企业客户锁定：私有部署 + 定制集成的切换成本极高
